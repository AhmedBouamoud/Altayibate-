# نظام الطيبات V6.1

فرع إنتاج مستقل لتطبيق نظام الطيبات، ولا يجب دمجه مع فرع `main` الخاص بالموقع التعليمي.

## النشر

- Production branch: `altayibate-v6`
- Netlify build command مضبوط في `netlify.toml`.
- تُفك الحزمة الموجودة في `release/` آلياً إلى مجلد `dist`.
- لا توجد مفاتيح سرية أو قاعدة بيانات أو تبعيات خارجية.

## الوظائف

- دليل أغذية قابل للبحث والمفضلة.
- فاحص مكونات يشرح نتيجة المطابقة وحدودها.
- مخطط وجبات أسبوعي قابل للتعديل والطباعة.
- دفتر متابعة محلي مع التصدير والاسترجاع.
- PWA قابلة للتثبيت والعمل دون اتصال.
- وضع ليلي وتخزين محلي يحترم الخصوصية.

## السلامة

التطبيق أداة تنظيمية لتوثيق قواعد النظام، وليس تشخيصاً أو وصفة علاجية. لا ينبغي إيقاف أي دواء أو تغيير علاج بناء عليه.
